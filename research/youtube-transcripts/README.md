# YouTube Transcripts

This folder contains transcripts from YouTube videos by the 10 experts in this research project.

## How transcripts were collected
1. Open the YouTube video
2. Click `...` below the video and select Show transcript
3. Copy the full transcript text
4. Paste into a .md file named expertname-short-video-title.md
